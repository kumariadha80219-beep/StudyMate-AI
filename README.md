# StudyMate AI

## Private On-Device AI Study Companion

StudyMate AI is an AI-powered study assistant designed to help students understand, summarize, and revise their study materials using on-device AI.

## Features

- 📄 PDF-based Question Answering
- 📝 Automatic Summarization
- ❓ AI-generated MCQ Quiz
- 🌐 Hindi and English Support
- 🔒 Privacy-focused local processing
- ⚡ Snapdragon AI optimization

## How It Works

PDF / Notes
↓
Text Extraction
↓
AI Processing
↓
Answer / Summary / Quiz

## Target Platform

Snapdragon-powered Windows PCs

## Technology

- Python
- AI/LLM
- PDF Processing
- Streamlit
- Qualcomm AI Hub
- Snapdragon Platform

## Project Goal

To provide students with a fast and privacy-focused AI learning assistant that can run on Snapdragon-powered devices.
